# Zverturet

Минималистичная русскоязычная лента коротких видео на Python и SQLite. Для запуска достаточно Python 3.10 или новее — внешние Python-библиотеки не нужны.

## Запуск в Windows

1. Открой папку `Zverturet`.
2. Запусти `run.bat` или выполни в терминале:

   ```powershell
   py -3 app.py
   ```

3. Открой в браузере [http://127.0.0.1:5050](http://127.0.0.1:5050).

Если команда `py` недоступна, выполни `python app.py` из установленного Python.

## Демо-вход

- Логин: `zverturet`
- Пароль: `12345678`

## Возможности

- Вход и выход из демо-профиля.
- Регистрация с проверкой сложности пароля: длина от 8 символов, заглавная и строчная латинские буквы, цифра и спецсимвол; генератор создаёт надёжный пароль на 16 символов.
- Вертикальная лента видео, вкладка «Для тебя» и фильтр подписок.
- Мем-видео с шутливыми надписями поверх роликов.
- Лайк и репост с изменением счётчиков.
- Подписка на авторов и актуальные счётчики подписок/подписчиков.
- Редактирование имени, логина и описания профиля.
- Светлая и тёмная чёрно-белые темы с сохранением настройки.
- Адаптация под телефон и компьютер.

Лайки, репосты, подписки, тема и профиль сохраняются в `instance/zverturet.sqlite3`. Видео в демо берутся с открытых демонстрационных источников и требуют подключения к интернету; для добавления собственных роликов понадобятся отдельные файлы и публикационная форма.

Пароли аккаунтов хранятся в SQLite в виде хеша PBKDF2-HMAC-SHA256 с отдельной случайной солью. После регистрации вход выполняется автоматически.

Сервер по умолчанию доступен только на этом компьютере (`127.0.0.1`). Перед размещением в интернете настрой отдельный секрет сессии через переменную окружения `ZVERTURET_SECRET` и используй полноценный веб-сервер с HTTPS.

## GitHub и публикация сайта

GitHub может хранить исходный код Zverturet, но GitHub Pages не запускает Python-сервер и SQLite. Чтобы сайт работал для всех в интернете, потребуется Python-хостинг с постоянной базой данных. Локальная папка `instance/` и базы данных исключены из Git, чтобы не публиковать аккаунты и их данные.
